# Gölge · Turco shadowing (A2)

App web para practicar turco con la técnica de *shadowing*: escuchar, hablar a la vez que la voz, repetir, grabarse y comparar.

**Abrir:** https://spanishgrows.github.io/turco-shadowing/

## Instalarla como app
- **Android (Chrome):** menú ⋮ → *Instalar app* / *Añadir a pantalla de inicio*.
- **iPhone (Safari):** botón Compartir → *Añadir a pantalla de inicio*.
- **PC (Chrome / Edge):** icono de instalar en la barra de direcciones.

## Qué incluye
- 9 temas A2 con traducción al español (presentarse, café, compras, transporte, rutina, pasado, futuro, salud, texto corrido).
- Voz turca del dispositivo, velocidad ajustable y modo lento.
- Puntuación palabra por palabra con reconocimiento de voz (Chrome, Edge, Safari).
- Modo manos libres, shadowing a ciegas y racha diaria.
- **Mis textos:** cada persona puede pegar sus propias frases. Se guardan solo en su dispositivo.

Consejo: usa auriculares para el shadowing.
